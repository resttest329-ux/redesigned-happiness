## Guidelines

Design the app UI in a pure Minimal style focused on simplicity and clarity. Use a refined grayscale palette: pure white or backgrounds, light grays from the tailwind palette for subtle backgrounds, medium grays from the tailwind palette for secondary text, and black or bold gray for primary text. Only use shadow-sm, you can use it for elements like cards. Avoid gradients, and unnecessary visual effects - maintain complete flatness throughout. Buttons should be primarily outline-style with thin 1px gray shade borders, transparent backgrounds, and subtle hover states that only change background to light gray. Active buttons and tabs should maintain the outline style but with a light shade gray background. For primary actions, use solid black buttons with white text. All elements should have minimal border radius like rounded-md or rounded-lg. Typography must be ultra-clean using system fonts (Inter, Body (14-16px, regular weight), Captions (12px, regular weight). Spacing should follow an 8px grid system with generous whitespace - minimum 16px between elements, 24-32px between sections. Forms use simple 1px borders light gray with clean rectangular inputs. Navigation should be ultra-simple - clean horizontal or vertical lists with subtle background changes for active states. The overall aesthetic should be distraction-free, content-focused, and timeless - perfect for professional documentation, minimal portfolios, and clean business applications that prioritize readability and function over decoration. If you add charts or graphs, apply a vivid color like blue, teal, orange etc to it. Apply a gradient color to area charts.
